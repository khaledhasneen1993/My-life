# Final-3 Pro

الكود الموجود في `final3_pro.py` يطبق تعديلات النسخة النهائية المطلوبة، ويظل البوت ملف Python واحدًا. هذا المشروع مستقل عن Final-3، ولا يتضمن لوحة التحكم القديمة.

## التشغيل

يتطلب Python 3.11 أو أحدث. داخل أوبونتو في تيرمكس:

```bash
cd /root
git clone https://github.com/khaledhasneen1993/My-life.git
cd My-life
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -u final3_pro.py
```

البوت يستخدم بيانات سوق Binance العامة، والتنفيذ داخلي افتراضي؛ لا يتطلب مفاتيح حساب تداول.

## سلوك النسخة المرفقة

- يبدأ الحساب الجديد برصيد 100 USDT، ويستأنف الحالة إن وجد ملف `paper_state_final3_pro.json` في مجلد التشغيل.
- هامش الدخول 10% حتى قوة 0.09، ثم يزيد خطيًا إلى 17% عند قوة 0.18 ويثبت عند هذا الحد: `10% + 7% × min(1, max(0, (strength - 0.09) / 0.09))`.
- الرافعة الافتراضية 50×، والحد الأقصى خمسة مراكز.
- تعزيز واحد عند انعكاس 2.5%، بنفس القيمة الاسمية للدخول الأول. يُرفض التعزيز إذا لم يكف الهامش المتاح لتغطية الهامش والرسوم.
- الوقف 7% من سعر التنفيذ الأول، والملاحقة تبدأ عند ربح 1.8% من متوسط الدخول وبمسافة 0.9%.
- انحياز 5 دقائق يزيد قوة الإشارة المتوافقة بنسبة 12%؛ لا يمنع الإشارات المعاكسة.
- مراقب خروج مستقل يفحص المراكز كل 8 ثوانٍ بالتوازي مع المسح. تُطلب أسعار المراكز بالتوازي؛ زمن الشبكة وانتظار القفل قد يؤخران الفحص. تبقى فترة المسح 600 ثانية.
- يُرفض الدخول والتعزيز والإغلاق إذا تجاوز عمر التيكر 12 ثانية أو غاب توقيته. تعاد المحاولة في الدورة التالية. لا يستخدم البوت WebSocket.
- ملف الحالة يحفظ آخر 150 تنفيذًا، مع سبب الخروج وقوة الإشارة ونسبة الهامش للدخول الجديد. تُطبع حالة الحساب وآخر ثلاثة تنفيذات كل 30 ثانية. تبقى حقول الحالة القديمة متوافقة ويُحفظ الملف باستبدال ذري.
- المحاكاة لا تحسب التصفية أو التمويل أو الانزلاق.

## التحقق

تم فحص الصياغة باستخدام `python -m py_compile final3_pro.py`. نجحت ثمانية اختبارات ببيانات وهمية تشمل الحجم والهامش وحداثة الأسعار والتريل بالاتجاهين وأولوية الوقف واستعادة الحالة واستقلال مراقب الخروج وتنظيف المهام عند الإيقاف. لم يتم تشغيله على سوق حي.
