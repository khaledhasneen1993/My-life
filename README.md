# Final-3 Pro

الكود الموجود في `final3_pro.py` محفوظ كما أرسله صاحب المشروع، دون تعديل منطق البوت. هذا المشروع مستقل عن Final-3، ولا يتضمن لوحة التحكم القديمة.

## التشغيل

يتطلب Python 3.11 أو أحدث. داخل أوبونتو في تيرمكس:

```bash
cd /root
git clone https://github.com/khaledhasneen1993/My-life.git
cd My-life
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -u final3_pro.py
```

البوت يستخدم بيانات سوق Binance العامة، والتنفيذ داخلي افتراضي؛ لا يتطلب مفاتيح حساب تداول.

## سلوك النسخة المرفقة

- يبدأ الحساب الجديد برصيد 100 USDT، ويستأنف الحالة إن وجد ملف `paper_state_final3_pro.json` في مجلد التشغيل.
- هامش الدخول 10%، ويرتفع إلى 15.5% إذا تجاوزت قوة الإشارة 0.09. الثابت MAX_MARGIN_PCT يساوي 17%، لكن المعادلة الحالية تبلغ 15.5% فقط.
- الرافعة الافتراضية 50×، والحد الأقصى خمسة مراكز.
- تعزيز واحد عند انعكاس 2.5%، بنفس القيمة الاسمية للدخول الأول. الكود الحالي يتجاوز فحص كفاية الهامش عند التعزيز.
- الوقف 7% من سعر التنفيذ الأول، والملاحقة تبدأ عند ربح 1.8% من متوسط الدخول وبمسافة 0.9%.
- انحياز 5 دقائق يزيد قوة الإشارة المتوافقة بنسبة 12%؛ لا يمنع الإشارات المعاكسة.
- فحص المراكز يتم بعد انتهاء مسح العملات، ثم ينتظر البوت 600 ثانية قبل الدورة التالية. لا توجد مراقبة خروج مستقلة كل 8 ثوانٍ.
- لا تتضمن هذه النسخة فحص حداثة الأسعار أو مراقب WebSocket الموجودين في Final-3.
- ملف الحالة يحفظ آخر 100 تنفيذ فقط؛ سبب الخروج يظهر في السجل ولا يُحفظ كحقل في التنفيذ.
- المحاكاة لا تحسب التصفية أو التمويل أو الانزلاق.

## التحقق

تم فحص الصياغة باستخدام `python -m py_compile final3_pro.py`. لم يتم تشغيل البوت على السوق أو التحقق من أدائه التشغيلي.
