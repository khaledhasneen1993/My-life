# Final-3 Pro — النسخة المعتمدة

النسخة المعتمدة في هذا المستودع هي `final3_pro.py` على فرع `main`. يحتوي الملف كامل البوت، وهو نقطة التشغيل الوحيدة للمشروع.

## الإعدادات المعتمدة

| الإعداد | القيمة |
|---|---|
| رصيد الحساب الجديد | 100 USDT افتراضي |
| هامش الدخول الأساسي | 10% من الرصيد |
| الحجم الديناميكي | زيادة خطية بعد قوة 0.09 حتى 17% عند قوة 0.18 |
| الرافعة | 50× |
| أقصى عدد مراكز | 5 |
| التعزيز | مرة واحدة عند انعكاس 2.5% من سعر الدخول الأول |
| قيمة التعزيز | نفس القيمة الاسمية للدخول الأول، مع تقريب كمية السوق |
| كفاية التعزيز | يجب توفر الهامش والرسوم في free |
| وقف الخسارة | 7% من سعر الدخول الأول؛ ثابت حتى تفعيل التريل |
| تفعيل التريل | ربح 1.8% من متوسط الدخول |
| مسافة التريل | 0.9%؛ يتحرك الوقف في اتجاه الربح فقط |
| مراقبة المراكز | مهمة مستقلة كل 8 ثوانٍ |
| حداثة السعر | رفض التنفيذ إذا تجاوز عمر التيكر 12 ثانية أو غاب توقيته |
| تحديث قائمة المسح | دورة مسح ثم انتظار 600 ثانية |
| الحالة المطبوعة | كل 30 ثانية، مع آخر ثلاثة تنفيذات |
| سجل الحالة | آخر 150 تنفيذًا |
| الرسوم | 0.05% لكل تنفيذ |

معادلة نسبة هامش الدخول:

```text
progress = min(1, max(0, (strength - 0.09) / 0.09))
margin_pct = 0.10 + (0.17 - 0.10) * progress
```

شروط الإشارة: حركة تتجاوز ±1.2%، وحجم يتجاوز 3.5 أضعاف المتوسط، وعدم توازن دفتر الأوامر يتجاوز ±0.35. تُفحص أعلى 40 عملة مؤهلة بحجم تداول يومي لا يقل عن 15 مليون USDT. الانحياز المتوافق من إطار 5 دقائق يزيد القوة 12%.

يُحفظ سبب الخروج SL أو TRAIL_SL في التنفيذ. تحمل الدخولات الجديدة قوة الإشارة ونسبة الهامش. عند رفض سعر قديم يبقى الحساب دون تنفيذ العملية، وتُعاد المحاولة في الدورة التالية الخاصة بها. طلبات أسعار المراكز متوازية، وقد تزيد مدة الشبكة وانتظار القفل زمن دورة المراقبة عن 8 ثوانٍ.

## التثبيت والتشغيل

يتطلب Python 3.11 أو أحدث. داخل أوبونتو في تيرمكس:

```bash
cd /root
git clone https://github.com/khaledhasneen1993/My-life.git
cd My-life
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -u final3_pro.py
```

ملف المتطلبات يثبت إصدارات المكتبات التي استُخدمت في الاختبارات.

## تحديث تثبيت موجود

أوقف العملية الحالية بـ Ctrl+C وانتظر حفظ الحالة وعودة المؤشر، ثم نفذ:

```bash
cd /root/My-life
git pull --ff-only
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -u final3_pro.py
```

شغّل عملية واحدة فقط على ملف الحالة نفسه. التحديث لا يحدّث العمليات الجارية تلقائيًا.

## الحالة والاستئناف

اسم الملف هو `paper_state_final3_pro.json` داخل مجلد التشغيل. يستأنف البوت الرصيد والمراكز والسجل منه إن كان موجودًا، ويبدأ بـ100 USDT إن لم يوجد.

تظل بنية الحالة السابقة مدعومة، وتضاف الحقول الجديدة عند الحفظ. لا تُختلق بيانات قوة الإشارة أو سبب الخروج لتنفيذات قديمة لم تسجلها. الحفظ باستبدال ذري لملف مؤقت، ويوقف البوت الاستعادة إذا كانت الحالة غير قابلة للقراءة أو كانت مجموعتا المراكز غير متوافقتين.

لا تحذف الحالة أثناء التحديث. الإيقاف يلغي المهام ويحفظ الحالة ويغلق اتصال البيانات.
